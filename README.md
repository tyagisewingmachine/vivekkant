# Vivek Kant — Business Executive
Premium editorial-style responsive portfolio prepared for GitHub Pages.

## Update the live site
1. Open your `vivekkant` GitHub repository.
2. Click **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, and `script.js` from this folder, replacing existing files.
4. Commit the changes to `main`. GitHub Pages will rebuild automatically.

## Important
- The feedback form is a demo only. It does not send or store messages. Connect a form provider and test it before accepting real submissions.
- This is a personal portfolio, not the official company website or official company complaint-resolution channel.
- The sewing machine illustration is CSS artwork, not a photograph of a real TSOL machine.
- Check all copy and contact links before sharing publicly. Do not publish personal phone numbers or a home address.
