# Vivek Kant — Business Executive website

Responsive static website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and demo form notice
- `assets/` — add approved images/logos here

## Important before publishing
The feedback form is a **demo only**. It does not send or save messages. Connect a form provider before launch (for example, Formspree or Netlify Forms), follow its current setup instructions, and test that submissions reach the intended private account. GitHub Pages alone cannot process form submissions.

The form is described as a personal feedback channel, not an official company complaint-resolution service. Avoid collecting passwords, payment credentials or unnecessary sensitive personal information.

Review before publishing:
- Confirm “Business Executive” is an appropriate title for your current role.
- Check all descriptions against your actual responsibilities.
- Change the public email or Instagram link if needed.
- Avoid publishing a personal phone number or home address unless you intend it to be public.
- Replace the abstract monogram with a portrait or genuine business imagery if you want.

## Preview locally
Open `index.html` in a browser. For better testing, use your editor's local preview/server.

## Free hosting: GitHub Pages
1. Create a GitHub account and a new public repository, such as `vivek-kant-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the URL shown in Pages settings (usually `https://YOUR-USERNAME.github.io/vivek-kant-portfolio/`).
7. Test all sections and links on a phone.

## Free hosting: Netlify
1. Create a Netlify account.
2. Deploy the folder with the manual deploy option if available, or connect your GitHub repository.
3. Add a form backend before using the feedback form.
4. Test the published page on mobile and desktop.

Free-tier terms can change; check each provider's current limits.
