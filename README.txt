- Opening intro uses the supplied Tyagi Sewing Machine Co. logo-reveal video, followed by “Presenting Vivek Kant”; the video is slightly zoomed on mobile to make the logo more visible while preserving proportions.

Filmmaking/video editing are described only as personal hobbies; no filmmaking portfolio card is featured.

CUSTOMER FEEDBACK AND COMPLAINTS
- Both personal feedback and company complaints submit ONLY to: tyagisewingofficial@gmail.com
- Customers must enter an email address. After the form endpoint is activated, the service emails an automatic acknowledgement to the customer and redirects the customer to thank-you.html for on-site confirmation.
- The form uses the free FormSubmit service (https://formsubmit.co/). Its email endpoint requires a one-time owner activation before public launch. The service retains form submissions for a limited period according to its own policies; review the provider's privacy terms before launch.
- Keep CAPTCHA enabled. The form intentionally uses a normal POST, not AJAX, so the autoresponse can work.
- Do NOT announce the form as live until activation and end-to-end delivery have been tested.
- Avoid collecting passwords, payment information, identity documents or other sensitive data. If adding attachments, the current client-side file check allows JPG/PNG/WEBP up to 5 MB; actual handling is by the external form provider.

IMPORTANT ONE-TIME ACTIVATION (FREE)
1. Upload the website package to your existing GitHub Pages repository.
2. Open the live site and submit a small test using an email you control.
3. Open the activation email delivered to tyagisewingofficial@gmail.com by FormSubmit and confirm/activate the form endpoint.
4. Submit another test. Confirm it arrives at tyagisewingofficial@gmail.com, the customer mailbox gets the autoresponse, and the browser opens thank-you.html.
5. Check Spam/Junk in both mailboxes. Only after all three checks pass should you share the form publicly.

DEPLOY TO EXISTING GITHUB PAGES REPOSITORY
1. Extract the ZIP.
2. Open the folder “vivekkant_personal_site”.
3. Upload the CONTENTS of that folder into the ROOT of your existing GitHub repository (not the ZIP and not a nested folder).
4. Replace index.html, styles.css, script.js, README.txt, thank-you.html and the full assets folder when prompted. Keep the assets folder structure.
5. Wait for GitHub Pages to deploy. Hard refresh or open an incognito tab after deployment.
6. If your published site URL differs from https://tyagisewingmachine.github.io/vivekkant/, update the hidden _next URL in index.html to your actual live URL + /thank-you.html, then re-upload.
